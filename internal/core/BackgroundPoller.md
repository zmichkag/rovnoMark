# BackgroundPoller Documentation

`BackgroundPoller` — это ключевой фоновый процесс в `PrinterManager`, отвечающий за мониторинг состояния оборудования в реальном времени.

## Описание работы

Метод запускается в отдельной горутине при старте приложения. Он представляет собой бесконечный цикл с задержкой в 5 секунд между итерациями.

### Основные функции

1.  **Мониторинг активных принтеров**: Процесс проходит по всем принтерам, зарегистрированным в системе, и проверяет их флаг `IsActive`. Опрос выполняется только для активных устройств.
2.  **Сбор телеметрии**: Для каждого активного принтера запрашиваются следующие параметры:
    *   `Status`: Текущий статус устройства (например, "Ready", "Printing", "Fault").
    *   `RemainingRibbon`: Остаток красящей ленты (риббона).
    *   `BufferFreeSpace`: Свободное место в очереди печати (количество кодов, которые можно дослать).
    *   `PrintSpeed`: Текущая скорость печати (кодов в минуту).
    *   `CurrentPrintCount`: Общее количество отпечатанных кодов.
    *   `CurrentTemplate`: Название текущего загруженного макета.
3.  **Обработка событий и логирование**:
    *   **Смена макета**: Если обнаружено, что текущий макет на принтере изменился по сравнению с предыдущим состоянием, событие фиксируется в системном логе.
    *   **Потеря связи**: Если при опросе возникает ошибка (например, сетевой таймаут), принтер помечается как "ОФФЛАЙН", и событие записывается в лог.
    *   **Восстановление связи**: При успешном опросе после периода недоступности фиксируется событие восстановления связи.
4.  **Обновление состояния (State Management)**: Все собранные данные сохраняются во внутреннем хранилище `pm.states`. Эти данные затем используются API-методами для отображения актуальной информации в пользовательском интерфейсе.

## Логика обработки ошибок

Если принтер недоступен (`err != nil` при вызове `GetStatus`):
*   Если это первая ошибка после успешной работы, записывается лог "ПОТЕРЯ СВЯЗИ".
*   Статус принтера обновляется на "ОФФЛАЙН: [ошибка]".
*   Все числовые показатели (скорость, очередь и т.д.) устанавливаются в значение "N/A".

## Конфигурация

*   **Интервал опроса**: 5 секунд (захардкожено в `time.Sleep(5 * time.Second)`).
*   **Логирование**: Хранятся последние 50 записей событий для каждого менеджера.
